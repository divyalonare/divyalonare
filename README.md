## Featured Projects

### [API Rate Limiter](https://github.com/divyalonare/rate-limiter-gateway)

A distributed rate-limiting gateway with consistent request limits across multiple server instances.

- Implemented Fixed Window and Sliding Window Counter algorithms using Redis.
- Added PostgreSQL-backed API-key quotas with cache-first lookup and database fallback.
- Designed fail-open and fail-closed behavior for graceful Redis outage handling.

`Node.js` `Express.js` `Redis` `PostgreSQL` `ioredis`

### [HR Management System](https://github.com/divyalonare/HR-Management-System)

A role-based HR management REST API for Admin, HR, and Employee workflows.

- Added JWT authentication and role-based authorization.
- Implemented employee, leave-management, and administrative analytics workflows.
- Used centralized validation and error handling for maintainable APIs.

`Node.js` `Express.js` `MongoDB` `Mongoose` `JWT`

### [Discord AI Bot](https://github.com/divyalonare/discord-ai-bot)

An event-driven Discord bot with slash commands and role-based user access.

- Built message and command handlers using Discord.js v14.
- Added MongoDB-backed user management with Admin and Normal User roles.
- Integrated the Discord REST API for custom command registration.

`JavaScript` `Node.js` `Discord.js` `MongoDB` `Mongoose`
